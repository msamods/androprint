📖 Quick Setup Guide

1

Install Cloudflare Tunnel

Download cloudflared on your Termux or server machine.

2

Start the Tunnel

Run cloudflared tunnel --url http://localhost:3000 to create a public URL.

3

Register the URL

Copy the generated URL and paste it above to enable cloud printing.

4

Print from Anywhere!

Use the cloud URL as your print API endpoint. Same API, global access. 🌍

🔌 API Endpoints

  • POST /print Send text to printer
  • POST /api/printer/test Test a printer
  • GET /api/printers List all printers
  • GET /api/server Server info & stats
  • GET /api/events SSE real-time stream

💻 Example Request

# Print via Cloud curl -X POST "http://localhost:3000/print" \ -H "Content-Type: application/json" \ -H "x-client-id: YOUR_CLIENT_ID" \ -H "x-print-key: YOUR_PRINT_KEY" \ -d '{"printerId":"Cashier1","text":"Hello Cloud!"}'
