# ⚡ Webhook-Based Auto Printing Guide

AndroPrint includes a dedicated, zero-configuration **Webhook Auto-Print Engine**. Any external e-commerce store, POS, restaurant platform, or Telegram/WhatsApp bot can send order webhooks to AndroPrint to automatically trigger physical thermal bills.

---

## 📡 Webhook Endpoints

| Platform | Webhook URL | Method | Payload Type |
|---|---|---|---|
| **Universal / Generic** | `http://<server-ip>:3000/webhook/print` | `POST` | Custom JSON or plain text |
| **Direct to Printer** | `http://<server-ip>:3000/webhook/print/:printerId` | `POST` | Direct to specific printer |
| **WooCommerce** | `http://<server-ip>:3000/webhook/woocommerce` | `POST` | Standard WooCommerce Order payload |
| **Shopify** | `http://<server-ip>:3000/webhook/shopify` | `POST` | Standard Shopify Order payload |
| **Telegram / Bots** | `http://<server-ip>:3000/webhook/telegram` | `POST` | Telegram bot / Food order payload |

> [!TIP]
> If using Cloudflare Tunnel or Ngrok, replace `http://<server-ip>:3000` with your public HTTPS tunnel URL (e.g., `https://print.yourdomain.com/webhook/woocommerce`).

---

## 🛍️ 1. WooCommerce Setup (Step-by-Step)

1. Open your **WordPress Admin Panel** → **WooCommerce** → **Settings**.
2. Go to the **Advanced** tab → Click **Webhooks**.
3. Click **Add Webhook**:
   - **Name**: `AndroPrint Kitchen Auto-Print`
   - **Status**: `Active`
   - **Topic**: `Order created` (or `Order updated` / `Order processing`)
   - **Delivery URL**: `https://<your-tunnel-or-ip>:3000/webhook/woocommerce`
   - **Secret**: *(Optional, configure same in AndroPrint Webhook Settings)*
   - **API Version**: `WP REST API Integration v3`
4. Click **Save Webhook**. Done! Whenever a customer places an order, your thermal printer prints the order bill, sounds the buzzer, and generates a UPI payment QR code automatically.

---

## 🛒 2. Shopify Setup (Step-by-Step)

1. Go to your **Shopify Admin** → **Settings** → **Notifications**.
2. Scroll down to **Webhooks** → Click **Create Webhook**.
3. Configure:
   - **Event**: `Order creation` (or `Order payment`)
   - **Format**: `JSON`
   - **URL**: `https://<your-tunnel-or-ip>:3000/webhook/shopify`
   - **Webhook API version**: Latest
4. Click **Save**.

## ⚙️ Webhook Automation Rules

Manage webhook behaviors in the **Webhook Auto-Print Hub** (`http://<ip>:3000/webhook.html`):
- **Default Printer**: Route all webhooks to a specific counter or kitchen printer.
- **🔔 Kitchen Buzzer**: Sound acoustic beep on ticket print.
- **📲 Dynamic UPI QR**: Auto-calculate bill total and print Google Pay / PhonePe QR code.
- **💵 Cash Drawer Kick**: Automatically pop open register drawer on new orders.
- **✂️ Auto Paper Cut**: Automatically execute partial or full paper cut.
